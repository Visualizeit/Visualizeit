## 代表项目

### [Illustrator](https://github.com/Visualizeit/illustrator)

<a href="https://github.com/Visualizeit/illustrator">

一个无需图像生成模型、可在本地完成视觉设计与渲染的 Agent Skill。

它可以根据自然语言、内容、代码和已有图片生成设计成品，适合内容创作与开发工作流。
